# Дашборд Grafana для Chrony NTP

В этой директории находится готовый дашборд Grafana для шаблона мониторинга **Chrony NTP в Zabbix Agent 2**. Дашборд работает через официальный [плагин Zabbix для Grafana](https://grafana.com/grafana/plugins/alexanderzobnin-zabbix-datasource/) (`alexanderzobnin-zabbix-datasource`).

## Возможности

- **Индикаторы статуса системного времени (KPI)**: Карточки в реальном времени со смещением времени (Offset), стратумом (Stratum), статусом високосной секунды (Leap Status), IP-адресом активного источника, количеством синхронизированных пиров и дисперсией (Root Dispersion).
- **Смещение часов и стабильность**: График истории смещения системного времени, среднеквадратичного смещения (RMS offset) и смещения последней выборки (Last sample offset).
- **Задержка и дисперсия маршрута (Root Delay & Dispersion)**: Отслеживание задержки до корневых часов Stratum 1 и накопленной погрешности для раннего выявления сетевых проблем.
- **Частота и дрейф генератора (Frequency & Skew)**: Мониторинг коррекции локального таймера (ppm) и расчетной нестабильности (skew).
- **Динамические графики LLD-источников**: Автоматическое отображение всех обнаруженных NTP-серверов без ручной настройки (`chrony.source.offset[*]`, `chrony.source.delay[*]`).
- **Селекторы фильтрации**: Выпадающие списки группы хостов и конкретного хоста с автозаполнением из Zabbix.

## Требования

1. **Grafana** (версии 9.0+, 10.x или 11.x).
2. **Плагин Zabbix для Grafana** (`alexanderzobnin-zabbix-datasource`), подключенный к вашему Zabbix API.
3. К хосту должен быть привязан шаблон **Chrony by Zabbix agent 2** (или вариант Active).

## Установка

1. В веб-интерфейсе Grafana откройте **Dashboards** -> **New** -> **Import**.
2. Нажмите **Upload dashboard JSON file** и выберите файл `chrony-overview.json` (либо вставьте его содержимое).
3. В поле **Data Source** выберите ваш настроенный источник данных Zabbix.
4. Нажмите **Import**.
5. Выберите нужную группу хостов (**Host Group**) и целевой хост (**Host**) в верхнем меню дашборда.
